
# Scoring rules — Nepsis qualifier

## Signal / timing (0–4)
- 4 : financement/refinancement/M&A/recrutement project finance récent ou datable
- 3 : signal fort trouvé mais date peu claire
- 2 : AO, permis, construction, portefeuille actif
- 0 : aucun signal exploitable

## Fit EnR (0–3)
- 3 : au moins 2 preuves publiques EnR
- 2 : 1 preuve claire
- 0 : fit non démontré

## Maturité / activité projet (0–2)
- 2 : plusieurs signaux projet/portefeuille/financement
- 1 : 1 signal
- 0 : rien

## Persona evidence (0–1)
- 1 : finance/project finance/investment visible
- 0 : persona non trouvée

## Status
- CONTACT : score >= 8 ET signal fort
- WATCH : score 5–7, ou activité projet sans buying window suffisamment forte
- INSUFFICIENT : score < 5, moins de 2 sources, ou preuves insuffisantes

## Failure modes assumés
- homonymie
- mauvaise résolution parent/SPV
- source trop ancienne
- dates absentes
- résultats de recherche bruités
- AO gagné interprété trop vite comme buying window
